# Compound

In one line: Choose gains that feed the next gain and keep them, because rate and cycle count both multiply.

A gain **compounds** when it feeds the next gain. Growth at rate $r$ for $n$ cycles multiplies by $(1 + r)^n$. Both the rate and the number of cycles matter. Three conditions make it work:

- **Retention.** The gain is kept: written down, practiced, stored, built in.
- **Reinvestment.** The gain is used as input to the next cycle.
- **No ruin.** No single loss resets the total to zero. Avoid irreversible losses above all, because they end the series.

## What compounds

| Asset | How it compounds | Invest by | Decays when |
|---|---|---|---|
| **Knowledge** | Each concept makes the next easier to learn and connect | learning fundamentals first; linking new ideas to old | it is never used or never written down |
| **Experience** | Each attempt improves the prediction for the next | many short cycles with honest review | the same year is repeated without reflection |
| **Taste** | Better judgment picks better inputs, which train better judgment | studying the best work; comparing side by side | only your own work is seen |
| **Execution** | Finished work becomes assets, reputation, and tools | finishing and shipping; outline, finish, share | work is started and not finished |
| **Speed** | Faster loops give more iterations, so more learning per unit of time | shortening the time from change to feedback | speed costs quality that must be redone |
| **Memory** | Retained context removes rework | logs, decisions, notes where the next person finds them | records are scattered or never consulted |
| **Lineage** | Knowledge passed on keeps compounding after its maker | teaching, documentation, open work, apprentices | it lives in one head |

## What does not compound

- Activity that changes no outcome.
- Information read and not retained or used.
- Effort on things that reset: unrecorded fixes, unshared insight, work thrown away at each new start.
- Gains that depend on one fragile condition.

## Compounding when intelligence is cheap

If machines make knowledge and analysis abundant, look for what remains scarce: taste, trust, verified judgment, finished work in the physical world, relationships, and knowledge passed to others. Build and preserve those assets.

## Steps

1. List what you spend time on this week.
2. Mark each item: does it leave something that the next cycle will use?
3. Move time from items that reset to items that compound.
4. For each compounding item, name where its gain is retained.
5. Name the one loss that could reset everything, and protect against it first.
